# ✦ LUX AI

## Private Local AI Assistant

LUX AI is a smart local AI assistant designed to provide
text and vision-based AI interactions while keeping the
AI workflow local.

## 🚀 Features

- 💬 AI Text Chat
- 🖼️ Single Image Analysis
- 🖼️ Multiple Image Analysis
- 📎 Image Upload and Preview
- 💾 Recent Chat History
- 🔐 Login and Guest Access
- ⚙️ Settings Panel
- 🔒 Private AI Information
- ℹ️ About LUX AI
- 📜 Smooth Chat Scrolling
- 🌙 Modern Dark AI Interface

## 🧠 Technology Stack

- HTML5
- CSS3
- JavaScript
- Flowise
- Ollama
- Qwen2.5-VL
- Local Storage

## 🏗️ Architecture

```text
User
  ↓
LUX AI Web Interface
  ↓
JavaScript
  ↓

  ↓

  ↓
Qwen2.5-VL
  ↓
AI Response
